Privacy Policy - Shorts Crossposter

Last updated: 22 October 2026

Shorts Crossposter is a private tool operated by Julius Seguido (the "owner") to publish the owner's own original short videos to the owner's own YouTube channels. It is not offered to the public and has no other users.

What data the tool uses

  • Google Drive (read-only): reads video files and their description files from one folder in the owner's own Drive.
  • Google Sheets: reads performance numbers and writes an upload log in one spreadsheet owned by the owner.
  • YouTube Data API: uploads videos to the owner's own channels and reads basic channel and video information (titles, IDs, view counts).

How the data is used

The data is used only to choose which of the owner's videos to upload, to write their titles and descriptions, to upload them, and to log the result. No data is sold, shared with third parties, or used for advertising.

Storage and security

Access tokens are stored as encrypted secrets in the owner's private GitHub repository and are used only by the tool's automated jobs. Upload logs are kept in the owner's Google Sheet. No other copy of user data is kept.

Google API Services User Data Policy

Shorts Crossposter's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
